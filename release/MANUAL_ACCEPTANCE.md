# 实机验收清单

对象：RYJS Launchpad 1.0.0
用途：提交 PR 前在真实 Windows 11 + Windhawk 环境中逐项确认。

**状态说明**：本清单中所有条目默认是"待人工验收"。只有在本机实际操作并留下记录后，才能改成"通过"。离屏渲染、隔离测试和官方编译校验**不能**替代这些条目。

---

## 1. 验收方法

1. 在 Windhawk 中**新建**一个模组，粘贴根目录 `ryjs-launchpad.wh.cpp`，编译并启用。
2. 先禁用 Seamless Launchpad / Fullscreen Start Plus / Fullscreen Start（Launchpad style），避免同时接管开始菜单。
3. 每项测完在下面记录表写清结果、时间和异常现象；建议录屏，便于回看动画。
4. 出错时先看 `%LOCALAPPDATA%\Windhawk\Engine\ModsWritable\local@ryjs-launchpad\data-v1\` 下的 `start-state-trace.log` 与 Windhawk 的 mod 日志。

---

## 2. 验收项

### 2.1 启动台打开和关闭

| # | 操作 | 预期 |
| --- | --- | --- |
| 1 | 按 Windows 键 | 启动器在该显示器铺满工作区 |
| 2 | 再按一次 Windows 键 | 关闭 |
| 3 | Ctrl+Esc | 打开 |
| 4 | 点任务栏开始按钮 | 打开 |
| 5 | 按 Esc（搜索为空） | 关闭 |
| 6 | 点图标以外的空白 | 关闭 |
| 7 | 切到别的窗口再切回 | 启动器已关闭，不残留置顶窗口 |

### 2.2 开始按钮状态复位（**至少 5 次**）

针对两种任务栏分别测：

- [ ] 原生 Windows 11 任务栏
- [ ] StartAllBack / 经典任务栏（若已安装）

每次操作：点开始按钮打开 → 按 Esc 关闭 → 鼠标移开 → 观察按钮是否还有"按下/选中"外圈。

| 次数 | 原生任务栏 | StartAllBack |
| --- | --- | --- |
| 1 | | |
| 2 | | |
| 3 | | |
| 4 | | |
| 5 | | |

判定：5 次全部无残留才算通过。若某一次残留，记录时间点并保存 `start-state-trace.log`。

### 2.3 图标飞入与关闭动画

| # | 操作 | 预期 |
| --- | --- | --- |
| 1 | 打开启动器 | 图标按设定方式飞入/淡入，无跳帧、无错位 |
| 2 | 收起过程中再按一次 Windows 键 | 动画平滑反向，不闪黑、不卡死 |
| 3 | 设置 → 外观，把打开/关闭时长分别改成 150 ms 与 800 ms | 时长差异明显生效 |
| 4 | 开启"减少动画" | 过渡直接完成，不播放飞入 |
| 5 | 连续快速开关 10 次 | 不残留半透明窗口，CPU 不持续占用 |

### 2.4 搜索与应用启动

| # | 操作 | 预期 |
| --- | --- | --- |
| 1 | 输入中文应用名的一部分 | 结果正确，首字匹配优先 |
| 2 | 输入英文名（大小写混用） | 结果正确 |
| 3 | 对已改名的入口，输入原名与别名 | 两种都能命中 |
| 4 | 回车启动第一个结果 | 应用正常启动 |
| 5 | 右键 → 以管理员身份运行 | 正常提权 |

### 2.5 网页图标获取（**至少 5 次**）

对 5 个不同站点各执行一次"添加入口 → 网址 → 保存"，然后观察图标：

| 次数 | 站点 | 图标是否出现 | 失败时是否回退地球占位 |
| --- | --- | --- | --- |
| 1 | | | |
| 2 | | | |
| 3 | | | |
| 4 | | | |
| 5 | | | |

再测一次"右键 → 重新获取图标"，确认能刷新且不重复发起请求。断网状态下添加应失败但不崩溃。

### 2.6 现有分组、布局和设置完整保留

| # | 检查 | 预期 |
| --- | --- | --- |
| 1 | 升级前后对比分组数量、名称、顺序 | 完全一致 |
| 2 | 每个分组内应用数量 | 完全一致 |
| 3 | 分组尺寸与位置（若曾手动调整） | 完全一致 |
| 4 | 设置项（语言、字体、主题、时长、帧率上限） | 保持原值 |
| 5 | 自定义图标与改名 | 保持 |
| 6 | 备份后再导入 | 数据回到备份时状态，旧数据留在旁侧目录 |

### 2.7 兼容性

| # | 检查 | 预期 |
| --- | --- | --- |
| 1 | 记录 Windows 版本（`winver`） | 例如 24H2 (26100.x) |
| 2 | 记录 Windhawk 版本 | 1.7.3 或 2.0 |
| 3 | 双屏（若可用）切换主屏 | 启动器跟随设定，工作区正确 |
| 4 | 缩放 150% / 200% | 图标与文字不模糊、不重叠 |
| 5 | 锁屏后解锁 | 启动器未残留，快捷键正常 |

### 2.8 启用/禁用/卸载

| # | 操作 | 预期 |
| --- | --- | --- |
| 1 | 在 Windhawk 中禁用模组 | 开始菜单恢复原生行为，无残留窗口 |
| 2 | 重新启用 | 启动器回来，布局不丢 |
| 3 | 连续禁用/启用 5 次 | 每次都能正常加载，无卡死 |
| 4 | 卸载模组 | 开始菜单、开始按钮行为恢复正常 |

## 5. 判定规则

- **通过**：在本机实际执行，结果与预期一致，并记录了 Windows 与 Windhawk 版本。
- **待人工验收**：尚未在本机执行。任何自动化测试、离屏渲染、编译通过都**不能**把这一项升级为"通过"。
- **失败**：记录操作序列、现象、日志路径；先判断是否阻断发布（崩溃、无法打开、数据丢失为阻断；外观细节不阻断）。
